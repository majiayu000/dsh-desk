# Support and community

Use [GitHub Discussions](https://github.com/majiayu000/dsh-desk/discussions) for setup questions, product ideas, clean-machine test reports, and plugin author coordination. Search existing conversations before starting a new one so that repeated installation failures accumulate in one discoverable place.

Use [Issues](https://github.com/majiayu000/dsh-desk/issues/new/choose) only for reproducible bugs and plugin verification requests.

## Include in a support request

- DSH Desk version;
- operating system and architecture;
- stable error code, if one is shown;
- minimum reproduction steps;
- expected and actual behavior.

Remove API keys, prompts, model responses, usernames, full workspace paths, private repository addresses, cookies, headers, and raw tool output before posting.

Report security vulnerabilities privately through [GitHub Security Advisories](https://github.com/majiayu000/dsh-desk/security/advisories/new), not in a public Discussion or Issue.
