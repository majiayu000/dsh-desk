安装与常见问题

先完成首个任务。
再添加你的插件。

这里的 DSH Desk 指 majiayu000/dsh-desk 维护的社区桌面发行版。请使用本项目的下载和兼容性记录核对下面的步骤。

怎样安装并开始首个任务？

进入 Releases，阅读发行说明，选择与你的系统和架构一致的安装包：macOS DMG、Windows x64 安装程序，或 Linux x64 AppImage/deb。打开 DSH Desk，在 Harness 引导页选择模型提供方，再发送一个小任务。模型访问由 Harness 配置。

需要安装 Node.js 或使用终端吗？

桌面安装包自带 Node 和 Harness 运行时，不需要系统另装 Node.js。源码构建使用另一套开发工具，按开发说明操作。内置运行时不代表模型请求可以离线完成。

这是 DeepSeek 官方桌面应用吗？

不是。DSH Desk 是独立社区项目，与 DeepSeek 无从属或官方背书关系，承载的是上游 Harness 界面。其他同名桌面外壳有各自的维护者、数据路径和发行策略；不能用另一项目的说明判断本项目的行为。

下载版本为什么和状态页不同？

发行说明标明实际发布的桌面版及其内置 Harness 版本。兼容性雷达检查的是仓库和上游候选版本；绿色检查不等于新安装包已发布。请结合验证矩阵核对。

怎样找到并安装插件？

先在 Harness Registry 浏览，再打开 DSH Desk → Plugins…，核对包名、版本、来源、完整性、权限和兼容性后安装。复制的 dsh plugin add 命令也进入同一审查流程。Manifest 验证不是安全审计，也不表示插件已进入桌面的可信目录。作者可从插件模板和目录提交说明开始。

启动失败或插件出错怎么办？

先用发行说明和公开检查核对已安装版本，记下桌面版本、系统与架构、显示的错误码和最小复现步骤。安装问题可去 Discussions，可复现的缺陷提交 Issue。按支持清单整理材料，发送前删除密钥、提示词、模型回复和私人路径。
