Setup & common questions

Your first task.
Then your first plugin.

DSH Desk is the community desktop distribution maintained at majiayu000/dsh-desk. Use this project's downloads and compatibility evidence when following these steps.

How do I install and start?

Open Releases, read the release notes, and choose the installer for your OS and architecture: macOS DMG, Windows x64 installer, or Linux x64 AppImage/deb. Open DSH Desk, choose a model provider in Harness onboarding, and send a small first task. Provider access is configured in Harness.

Do I need Node.js or a terminal?

The desktop download bundles its Node and Harness runtime. It does not require a system Node.js installation. Building from source uses a separate development toolchain; follow the development instructions for that path. Bundling a runtime does not make model-provider requests offline.

Is this an official DeepSeek app?

No. DSH Desk is an independent community project, not affiliated with or endorsed by DeepSeek. It hosts the upstream Harness UI. Other desktop wrappers have their own maintainers, data locations, and release policies; their instructions do not establish this project's behavior.

Which version am I downloading?

The release notes identify the published desktop and bundled Harness versions. The compatibility radar checks repository and upstream candidates; a green check does not publish a new installer. Read the verification matrix before equating source versions with downloads.

How do I add a plugin?

Browse Harness Registry, then open DSH Desk → Plugins… to review the exact package, version, source, integrity, permissions, and compatibility before installation. A copied dsh plugin add command enters the same review flow. Manifest verification is not a security audit or inclusion in the desktop's trusted catalog. Authors can start with the plugin template and registry submission guide.

What if startup or a plugin fails?

Compare your installed release with the public checks and its release notes. Record the desktop version, OS/architecture, displayed error code, and minimal steps. Use Discussions for setup help or Issues for a reproducible bug. Follow the support checklist and remove keys, prompts, responses, and private paths before posting.
