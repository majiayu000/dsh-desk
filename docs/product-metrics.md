# 产品指标与隐私门禁

## 北极星漏斗

```text
看到 Release → 下载 → 安装成功 → runtime 就绪 → 配置模型 → 完成首次任务 → 7 日继续使用
```

| 指标 | 首阶段目标 | 事件边界 |
|---|---:|---|
| 安装成功率 | ≥95% | 平台安装器与首次启动配对，不能只看下载量 |
| runtime 首次启动成功率 | ≥95% | `starting → ready`，失败按稳定错误码聚合 |
| 首次任务成功率 | ≥85% | 必须由上游提供不含任务内容的完成信号后才能统计 |
| 无崩溃会话占比 | ≥99% | 只记录进程/版本/错误码，不记录对话 |
| 7 日留存 | ≥25% | 使用随机安装 ID；用户关闭遥测后停止记录 |
| 上游不兼容发现时间 | ≤4 小时 | GitHub Actions 运行记录 |
| 已支持版本修复或阻断 | ≤24 小时 | Release/Issue 时间线 |

## 允许采集

- 随机生成、可重置的安装 ID；
- Desktop、DSH、Node、OS 和架构版本；
- 安装、启动、更新、回滚等有限事件名；
- 稳定错误码和耗时区间；
- 用户主动选择的遥测开关。

## 禁止采集

- API Key、Cookie、Authorization header；
- 提示词、模型响应、会话标题和工具输入输出；
- 文件名、完整工作区路径、用户名、主机名；
- 环境变量、SSH 信息、Git remote 私有地址；
- 插件私有配置和模型 provider 凭据。

## 上线门禁

当前仓库没有遥测后端，因此不能声称已经掌握激活率或留存。接入任何服务前必须：

1. 在首次启动明确说明并允许拒绝；
2. 发布事件 schema、保留期、删除方式和接收域名；
3. 用测试证明禁止字段不会进入 payload；
4. 关闭遥测后核心功能完全可用；
5. 先用 10–20 名明确同意的测试用户验证指标是否可解释。

在此之前，安装成功和首次任务数据通过知情测试用户的观察表采集，不使用下载量或 Star 代替留存。
