# 发布节奏

## 每周小版本

- 周一：整理上游变化、兼容失败和真实用户阻断；
- 周二至周三：只实现本周一个用户可感知主题；
- 周四：三平台 CI、固定 runtime、插件 parity、升级和卸载门禁；
- 周五：生成签名草稿 Release，附演示、哈希、兼容矩阵、已知问题和恢复方式；
- 发布后：监控安装失败与崩溃，不在周末合入高风险 runtime 变更。

没有用户变化时不为追求频率空发版本。重大上游不兼容可以当天发布兼容修复，但仍必须通过相同门禁。

## 每月主题版本

每月只突出一个主题，例如“Windows 正式支持”“runtime 原子回滚”或“可信插件安装”。主题版本需要：

- 20–30 秒真实录屏；
- 一个可复现的用户问题和前后对比；
- 三平台状态、签名主体和兼容版本；
- 指标结果与仍未解决的问题。

## 版本说明模板

1. 本版本唯一主题；
2. 用户能感知的变化；
3. DSH/Node/平台兼容矩阵；
4. 安装包签名、公证、SHA-256 和 provenance；
5. 升级、回滚和卸载说明；
6. 已知问题；
7. 贡献者与插件作者。
